스테파노 · stephango.com

왜 읽기 목록이 실패하는가

대부분의 "나중에 읽기" 목록은 무덤이 된다. 저장하는 행위 자체가 이미 소비했다는 착각을 주기 때문이다. 실제로 다시 열어보는 비율은 5%도 되지 않는다는 조사 결과도 있다.

중요한 건 저장 방법이 아니라 다시 만나는 방법이다.

대신 매주 15분씩 목록을 훑어보며 세 개만 남기고 나머지는 과감히 지우는 루틴을 권한다. 이렇게 하면 큐가 항상 가볍게 유지되고, 정말 읽고 싶은 글만 남는다.
