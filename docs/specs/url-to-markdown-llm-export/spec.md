# URL → Markdown → LLM 전달 서비스

승인된 화면 구조·상태·상호작용: [`prototype.html`](./prototype.html) (단일
화면, Default/Loading/Error/Result 상태).

## 개요

사용자가 웹 페이지 URL을 붙여넣으면 본문을 Markdown으로 추출해 보여주고,
그 결과를 복사·다운로드하거나 프롬프트를 붙여 ChatGPT·Claude로 곧장 넘길 수
있게 한다.

## 사용자 흐름 및 관찰 가능한 동작

### 1. 입력
- 사용자는 URL을 입력창에 붙여넣는다.
- 지우기 버튼을 누르면 입력창과 이후 모든 결과(변환 결과, 선택된 프롬프트)가
  초기 상태로 리셋된다.

### 2. 변환
- 유효한 URL을 제출하면 서버가 해당 페이지를 가져와 `defuddle`
  (`defuddle/node`, https://defuddle.md/docs)로 본문을 Markdown으로 추출한다.
- 변환이 진행되는 동안 사용자는 로딩 상태를 확인할 수 있다.
- 변환 실패 시(페이지를 가져올 수 없음, 본문 추출 실패 등) 사용자는 실패
  사실과 재시도 가능 여부를 확인할 수 있는 에러 상태를 본다.

### 3. 결과 확인
- 변환 성공 시 다음이 화면에 표시된다:
  - 페이지 제목 · 저자로 구성된 헤더 (defuddle이 추출하지 못한 값은 표시하지
    않는다)
  - 렌더링된 Markdown 본문
- 사용자는 소스 URL로 돌아가 다른 URL을 다시 시도할 수 있다.

### 4. 내보내기
사용자는 변환된 결과를 아래 방법 중 하나로 내보낼 수 있다.

- **복사하기** — Markdown 본문을 클립보드에 복사한다.
- **.md 파일 다운로드** — Markdown 본문을 `.md` 파일로 저장한다.
- **ChatGPT로 열기 / Claude로 열기** — 다음 동작을 수행한다:
  1. 프롬프트(선택된 경우)와 Markdown 본문을 합친 텍스트를 클립보드에
     복사한다.
  2. 새 탭에서 각각 chatgpt.com / claude.ai를 연다.
  3. 사용자는 새 탭에서 직접 붙여넣어(Ctrl+V) 전송한다.

  **제약 (기술적으로 확인됨):** ChatGPT와 Claude 웹 인터페이스는 URL을 통한
  프롬프트 자동 입력을 공식적으로 지원하지 않는다 — Claude.ai의 `?q=`
  파라미터는 제거되었고, ChatGPT도 브라우저 확장 없이는 지원하지 않는다.
  따라서 자동 붙여넣기·자동 전송은 범위 밖이며, 클립보드 복사 + 새 탭 열기 +
  수동 붙여넣기가 최종 동작이다. 사용자가 이 제약을 확인하고 승인함.

### 프롬프트 선택
- 사용자는 내보내기 전 프롬프트를 선택할 수 있다: **요약해줘 / 한국어로
  번역해줘 / 쉽게 설명해줘** 프리셋, 또는 **직접 입력**.
- "직접 입력" 선택 시 텍스트 인풋이 노출된다. 이 입력은 세션에 저장되지
  않으며 페이지를 나가거나 리셋하면 사라진다(1회용).
- 프롬프트는 선택 사항이다 — 아무것도 선택하지 않으면 Markdown 본문만
  전달된다.
- 복사하기 / .md 다운로드는 프롬프트를 포함하지 않고 항상 Markdown 본문만
  대상으로 한다. 프롬프트는 "ChatGPT·Claude로 열기" 내보내기에만 적용된다.

### 다크모드
- 사용자는 라이트/다크 테마를 토글할 수 있다.

## 승인된 범위

- 단일 URL 입력 → 단일 변환 결과를 다루는 한 화면 흐름.
- 위 4가지 내보내기 경로(복사·다운로드·ChatGPT 열기·Claude 열기).
- 3개 프리셋 프롬프트 + 1회용 직접 입력 프롬프트.
- 다크모드 토글.

## 범위 밖

- ChatGPT·Claude로의 자동 붙여넣기/자동 전송 (기술적으로 불가능함이 확인됨).
- 변환 이력 저장, 여러 URL 동시 처리, 사용자 계정·로그인.
- 프롬프트 프리셋의 사용자 편집/추가/저장.
- 페이월·로그인 필요 페이지, 강한 봇 차단 사이트의 우회 처리 — 이런 페이지는
  변환 실패로 처리된다(아래 리스크 참고).

## 가정 (경미하고 되돌리기 쉬움 — 에이전트가 결정)

- 결과 헤더는 제목·저자만 표시하고, defuddle이 값을 추출하지 못하면 해당
  항목을 생략한다(빈 칸 대신).
- `.md` 다운로드 파일명은 페이지 제목을 슬러그화한 값을 사용하고, 제목이
  없으면 `untitled.md`를 사용한다.
- URL 유효성 검사는 기본적인 형식 검사(스킴·호스트 존재)로 한정하고, 실제
  접근 가능 여부는 변환 시도 결과로 판단한다.
- 변환 중에는 버튼 비활성화 등으로 중복 제출을 막는다.

## 남은 리스크

- **봇 차단·페이월 사이트**: 서버가 페이지를 직접 fetch하므로, 봇 탐지가
  강하거나 로그인이 필요한 사이트는 변환이 실패할 수 있다. 이 경우 사용자는
  실패로만 인지하며 우회 수단은 제공하지 않는다.
- **defuddle 추출 품질**: 본문 추출 정확도는 defuddle 라이브러리의 동작에
  의존하며, 페이지 구조에 따라 본문이 아닌 요소가 섞이거나 본문 일부가
  누락될 수 있다.
- **클립보드 API 가용성**: 클립보드 복사는 브라우저의 Clipboard API에
  의존한다. 권한이 거부되거나 미지원 환경에서는 대체 동작(예: 수동 선택 안내)
  이 필요할 수 있으며, 이는 구현 시 확인이 필요하다.
